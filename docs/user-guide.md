# Керівництво користувача

## Ролі

- **Адміністратор** — реєстрація користувачів, імпорт логів, навчання й активація ML-моделей, аналіз, сповіщення.
- **Аналітик** — імпорт логів, запуск аналізу, перегляд статистики та журналу попереджень. Навчання моделей недоступне.

## Типовий сценарій

1. Відкрийте frontend: http://localhost:8080
2. Зареєструйте обліковий запис (для демонстрації оберіть роль `Адміністратор`).
3. Увійдіть — відкриється dashboard.
4. На сторінці **Network Logs** або dashboard завантажте `docs/sample_logs.csv`.
5. На сторінці **ML Models** навчіть модель (Random Forest або Isolation Forest).
6. На dashboard натисніть **Запустити аналіз**.
7. Перегляньте графіки, таблицю загроз, сторінку **Alerts** і деталі інциденту.

## Сторінки

| Сторінка | Призначення |
|----------|-------------|
| Вхід / реєстрація | JWT-аутентифікація |
| Dashboard | лічильники, графіки, імпорт, запуск аналізу |
| Network Logs | список подій, імпорт CSV/JSON, видалення |
| Інцидент | деталі загрози та пов’язаного логу |
| Alerts | журнал попереджень і зміна статусу |
| ML Models | навчання, метрики, активація моделі |
| Profile | дані поточного користувача |
| Settings | URL API та перевірка `/health` |
